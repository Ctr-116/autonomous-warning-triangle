# Autonomous Warning Triangle

自行走三角警示牌项目，用于项目资料、研发进度、软硬件设计和测试记录管理。

## 项目目标

设计并实现一种能够自主移动、部署和回收的三角警示牌系统，提高道路故障、施工或应急场景下的安全性和部署效率。

## 仓库结构

- `docs/`：项目文档、背景资料、方案说明
- `project-management/`：人员安排、任务清单、会议纪要、进度周报
- `hardware/`：硬件设计、电路资料、器件清单
- `software/`：控制程序和相关代码
- `mechanical/`：机械结构设计资料
- `tests/`：测试记录和实验数据
- `assets/`：图片、展示图和演示素材

项目初始化阶段。
