# 原始入口静态核查说明

这里保留四组静态映射报告，记录原 ROS 1 的 282 个非缓存源码、启动和动态配置入口。`verification.json` 检查是否遗漏条目或引用了不存在的路径，不证明功能等价或运行成功。

用户最终选择工作量较少的 ROS 2 主线方案。因此，报告中的 `missing` 和 `needs_review` 对应旧 SLAM、探索、Gazebo、Warehouse、额外规划器、复杂传感器组合、旧标定/调参和备份入口时，已按范围排除，不再作为必须补齐的待办。完整清单见 `../../docs/迁移范围与未移植项.md`。

`mapped` 仅表明有对应源码或上游入口，不表示外部硬件驱动或 ORB SDK 已安装。`pure_example` 不表示 ROS 2 节点；其中 21 个 OpenCV 教学脚本已经保留，独立的 `AR/test.py` 因缺少标定资源而排除。

运行结果以 `../../docs/验证结果.md` 和随包的主线验证记录为准。这个目录中的原始分类保留了审计时的状态，用于追溯，不将未实现项改名为“已完成”。
