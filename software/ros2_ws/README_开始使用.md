# X3plus ROS 2 Humble 主线迁移版

请先阅读 [主说明](README.md) 和 [开始使用](docs/开始使用.md)。

- [迁移范围与未移植项](docs/迁移范围与未移植项.md)：按你的选择采用 Nav2、slam_toolbox、MoveIt 2 主线，列出未保留的旧算法与可选演示。
- [本地验证结果](docs/验证结果.md)：22 包干净构建、307 项单元测试及实际软件/虚拟串口验证范围。
- [接口与迁移说明](docs/接口与迁移说明.md)：速度、里程计、机械臂、灯光、语音与命名空间接口。
- [可选视觉依赖](docs/可选视觉依赖.md)：MediaPipe、ONNX Runtime、dlib 及官方模型资源准备。
- [实车验收](docs/实车验收.md)：能连接 Jetson 后的待测项目。

本地检查使用 x86_64 Ubuntu 22.04 / ROS 2 Humble，未进行 Jetson ARM64 或实际小车验收。历史底盘阶段记录仅作为开发历史保存，不代表完整主线版本的当前构建和测试数量。
